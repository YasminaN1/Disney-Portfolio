Christmas Buzzfeed Quiz

Description

This project is a playful holiday quiz experience inspired by Buzzfeed-style interactions. It pairs bold seasonal imagery with a fun question flow that keeps users engaged through each step.

Code Used

The quiz was built with HTML, CSS, and JavaScript. I used JS event listeners and DOM updates to move between quiz questions. CSS transitions and color changes were added to create a festive, interactive feel.

What I Learned

  • How to structure quiz logic with JavaScript and state management.
  • How to make small animations and hover states feel cohesive in a fun UI.
  • How to keep interactive content readable and visually consistent across steps.
