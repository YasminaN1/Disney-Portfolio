Christmas Buzzfeed Quiz

Description

This is a single-page interactive Christmas quiz that asks users eight questions about their home's holiday aesthetic — things like how their tree looks or how decorated their living room is — and matches them to a Christmas song based on their answers. The result screen shows an animated vinyl record that slides out from behind the album cover and plays the matched song automatically.

Code Used

The code here represents a significant step forward because it's the most JavaScript-heavy project so far, and the logic is genuinely well-structured. The quiz data is stored as an array of objects, each holding a question and its image-based answer options with a type tag. A separate object acts as a lookup table that maps each result type to a song title and album art, and another maps it to an audio file. When the quiz ends, a reduce function tallies which answer type appeared most and looks up the result — a clean and efficient approach to handling quiz logic. The vinyl animation is handled through CSS keyframes, with one animation spinning it continuously and another sliding it out from behind the album cover, which is a satisfying visual touch. The audio element is controlled through JavaScript, and clicking the vinyl toggles play and pause.
