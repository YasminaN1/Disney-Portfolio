Coral Cove

Description

Coral Cove is an illustration-driven website concept that emphasizes storytelling through color, texture, and layout. The design highlights a coastal mood with playful illustration elements and soft visual balance.

Code Used

Built with HTML and CSS, I used layered section styles and custom background treatments to create an illustrated world. The page uses responsive layout techniques and visual contrast to highlight key sections and imagery.

What I Learned

  • How to create an illustration-led page with strong visual storytelling.
  • How to use color and texture to give a design a distinct mood.
  • How to balance illustration and content for a polished portfolio presentation.
