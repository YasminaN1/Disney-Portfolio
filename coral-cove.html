Coral Cove

Description

This is a multi-page website for a fictional beachside coffee shop called Coral Cove Cafe. The site has five pages, a home page with the cafe's origin story, a menu page, a location and hours page, a contact page, and a merchandise page. The overall aesthetic is very coastal and warm, using coral pinks, soft pastels, and beach photography as backgrounds throughout.

Code Used

One of the more impressive things in this project is the animated SVG text on the home and menu pages, where a wave pattern literally ripples through the heading text using SVG gradients and animateTransform. That's a step beyond standard HTML and CSS and shows some creativity with inline SVG animation. The menu page also features a 3D flip effect where hovering over the menu cover rotates it open like a real book, using rotateY, backface-visibility, and transform-origin — a fairly advanced CSS 3D technique. The merchandise page is where the most complex CSS lives. Each product card uses CSS Grid to layer the product image, size, price, and color options on top of each other, and hovering the image triggers a clip-path animation that reshapes it into a star-like polygon while rotating it and fading in all the product details underneath. The footer is also well-built with responsive design using a @media query to restack the links on smaller screens, and Font Awesome icons for the social media links.
