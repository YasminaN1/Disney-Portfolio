Rangers Team Roster

Description

This is a two-page fan website dedicated to the New York Rangers. The home page is a cinematic landing page with a looping video background, a glitch-effect title, stacked cards with team history text, a glowing call-to-action button, and animated social media icons. The roster page displays all 26 players in a grid of cards with their photo, position, age, and a button that opens a Bootstrap modal with a fun fact about each player.

Code Used

The code here pulls together a lot of skills in a confident way. The glitch text effect on the home page is a clever pure-CSS technique that uses pseudo-elements with different colored clip-paths, each animating slightly out of sync to create that distorted glitch look. The glowing button is also built entirely in CSS using layered box-shadow and text-shadow values, giving it a neon light feel that fits the hockey aesthetic. The social media icons have a hover effect where each one reveals a tooltip and shifts to its platform's brand color, which is a nice interactive touch. On the roster page, all player data lives in a separate JavaScript file as an array of objects, and the roster script loops through it to dynamically build every card on the page rather than writing them out in HTML by hand. Clicking a player's fun fact button triggers a Bootstrap modal that gets populated with that player's info on the fly.
