Santorini

Description

Santorini is a scenic visual project inspired by coastal design and architecture. The page presents elegant color palettes, imagery, and layout choices that reflect a calm, Mediterranean aesthetic.

Code Used

Built with HTML and CSS, the project uses layered sections and thoughtful spacing to convey a refined aesthetic. I used responsive grid and flexbox patterns to keep the layout balanced across screen sizes.

What I Learned

  • How to design a visual system that feels cohesive and elevated.
  • How to use color and composition to create a mood-driven page.
  • How to make imagery and type work together in a calm interface.
