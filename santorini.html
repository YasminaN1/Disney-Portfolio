Santorini

Description

This is a multi-page travel guide website dedicated to Santorini, Greece. It covers five pages, a welcome/home page, a travel logistics page, a hospitality page, an excursions page, and a history page. The overall feel is dreamy and editorial, using deep blues, coral tones, and signature-style fonts to match the romantic aesthetic of the island. Content-wise it's genuinely informative, covering everything from fun historical facts and packing lists to real flight options and ground transportation bookings.

Code Used

The code across this project pulls from a mix of HTML, CSS, Bootstrap, and some creative animation techniques. Bootstrap handles the responsive navbar and card-style layout blocks throughout, while the CSS does the heavier lifting visually. There's a recurring animated heading effect where each letter of a word flips independently using CSS keyframe animations and CSS custom properties to stagger the timing per letter. The travel page also embeds a live weather widget and a Google Maps iframe, which introduces the idea of pulling in third-party tools directly into a webpage. The history and travel pages use frosted glass-style content boxes, and the CSS file includes a rich animated text shadow effect that builds and dissolves in a wave pattern.
