Tabayer

Description

Tabayer is a luxury campaign concept that showcases elegant layout design and bold typography in a polished brand presentation. The page highlights seasonal products and high-end visuals with a refined interface.

Code Used

Built with HTML and CSS, this project uses compositional hierarchy, elegant spacing, and refined text styling. I focused on establishing a premium visual language through subtle interactions and layered sections.

What I Learned

  • How to create a campaign landing page with a luxury feel.
  • How to support strong branding through spacing and typography.
  • How to design elegant content sections that feel polished and intentional.
