Tabayer

Description

This is a multi-page website built as a tribute to Tabayer, a fine jewelry brand founded by Nigora Tokhtabayeva. It spans three pages, a home page with the brand's mission, a founder page with Nigora's personal bio and fun facts, and a photos page showcasing celebrities wearing Tabayer pieces.

Code Used

The site leans heavily on Bootstrap 5 for its structure and components, using things like the responsive navbar, card layouts, and most notably a full image carousel on the photos page with captions and navigation controls. The CSS file is where a lot of the personality comes through. There's a frosted glass card effect using blur and transparency, a smooth animated underline that slides in on nav link hover, and different background images that swap out depending on which page you're on..
