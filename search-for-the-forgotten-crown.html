The Search For The Forgotten Crown

Description

This is a single-page mad lib style story generator themed around the TV show Outer Banks. When the page loads, a series of prompts ask the user for their name, a feeling, a place, a time, and a few other words, then plugs all of their answers into a pre-written adventure letter that gets displayed on top of a decorative letter image, set against an Outer Banks beach background.

Code Used

The code here is intentionally simple and focused, which is part of what makes it a good project. The entire interactive logic is just a handful of prompt calls storing user input into variables, then a template literal that weaves all those variables into a paragraph using the backtick syntax. That single line injecting the content into the page with innerHTML is doing all the heavy lifting. The CSS does something clever by layering the letter text directly on top of an image of a handwritten letter using precise padding, making it look like the words are actually written on the paper. The handwriting-style font and the glowing gold text shadow on the title add to the storytelling atmosphere.
