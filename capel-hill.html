Capel Hill

Description

Capel Hill is a senior portfolio project focused on brand expression and interactive layout. It presents a recruitment-style site with a strong visual hierarchy, expressive imagery, and polished content blocks that support the concept.

Code Used

This page was built with HTML for structure, CSS for responsive layout, and subtle interactions. I used flexbox for layout sections, custom typography styles, and color palettes to emphasize the brand. The hero and content cards rely on CSS gradients, border accents, and smooth hover states.

What I Learned

  • How to create a branded visual system with consistent spacing and imagery.
  • How to use CSS to enhance content emphasis without overwhelming the design.
  • How to balance readability with stylized layout components on a modern portfolio page.
