UNC Chapel Hill

Description

This is a four-page college recruitment website built for UNC Chapel Hill. It covers a welcome page, an academic programs page, a student life page, and a cost and financial aid page. The site has a polished, professional feel that matches the prestige of the school, using Carolina blue tones, campus photography, and a looping background video on the home page to immediately set the atmosphere.

Code Used

The code across the project draws heavily on HTML, CSS, and Bootstrap, but also introduces JavaScript in a meaningful way for the first time. The home page features a series of entrance animations where the logo, heading, slogan, and info cards all fade and slide in sequentially using CSS keyframe animations with staggered delays, giving the page a cinematic first impression. A looping video is used as a full-screen background, fixed behind the content using z-index layering with a semi-transparent overlay on top to keep text readable. The academic page goes further by using JavaScript to build an actual interactive filtering system, where clicking category buttons shows or hides faculty cards based on their department tag. There's also commented-out code for a quick-view modal, which shows you were experimenting with more complex popup functionality.
