KC Nail Art

Description

This is a single-page website built for a real nail art business called KC Nail Art, run out of Morganville, NJ. The page is divided into three sections — a welcome/hero section, a services collection, and a contact/booking section — all connected by smooth anchor link navigation. The aesthetic is luxurious and editorial, using a warm gold, blush, and cream palette with script fonts to communicate a high-end salon experience.

Code Used

The code here is noticeably more polished and intentional than earlier projects. CSS custom properties are used throughout to define the entire color palette in one place, making the design consistent and easy to adjust. The hero section layers multiple elements — a full background image, a dark overlay, and three animating rings that pulse using keyframes, to create depth without any images doing that work alone. Elements like the logo and headline fade and slide in on load through CSS animations with staggered delays, similar to the UNC project but more refined in execution. The service cards use a side-by-side image and text layout that collapses into a vertical stack on mobile, and the contact section uses a CSS Grid layout that reorganizes itself at tablet and mobile breakpoints. Scroll reveal is handled through the Intersection Observer API, and the mobile hamburger menu is built from scratch rather than relying on Bootstrap's built-in collapse component.
