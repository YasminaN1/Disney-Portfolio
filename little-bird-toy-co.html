Little Bird Toy Co.

Description

This is a four-page website for a fictional handcrafted wooden toy company called Little Bird Toy Co. The pages cover a welcome landing page, an about page with the brand story, a products page, and a contact page. The overall aesthetic is warm and earthy, soft oranges, cream tones, and natural textures, fitting for a brand centered around sustainable, handmade toys for children.

Code Used

The products page is the most technically interesting part of the project. It features a category filter system where clicking buttons like "Cars" or "Trains" shows only the relevant products, built with JavaScript that reads data attributes from each card and toggles their visibility. Clicking a product card opens a custom quick-view modal with the product's image, name, material, dimensions, and a description pulled from a JavaScript data object. Adding a product to cart triggers a toast-style notification that slides up from the bottom corner and disappears after a few seconds — a small but polished touch that makes the page feel like a real e-commerce site. The about page has a text animation where the page title fades in word by word, each span blurring into focus with a slight stagger, which is an elegant effect that suits the brand's gentle personality.
